# Captured batched-hint oracle

The two files in `testdata/` are immutable independent known-answer oracle
source and output retained for the
[2026-10-04 assurance capture](../../evidence/prewarm-hint-assurance-2026-10-04/README.md).
Their bytes come from tested commit
`2bb5c0299eb752b68a5ad5fad9b156b046bef8c9` and match the source SHA-256
hashes in that capture's unchanged manifest. They keep its relative links
usable offline. Do not regenerate or edit the captured output here.

This directory contains no Cargo package or production implementation.
The maintained implementation and oracle live in
[wallet-libraries](https://github.com/zakura-core/wallet-libraries/tree/1b0cda2e09c1e496889b2d85962321a8df750fea/zakura/transparent-native).
